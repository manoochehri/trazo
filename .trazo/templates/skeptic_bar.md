# Skeptic Bar

The minimum evidence quality required before a quantitative, experimental, or empirical result can be acted on.

Fill this in per project. What constitutes adequate evidence varies by domain and risk.

## Sample criteria

### Data quality
- [ ] Sample size justified with power analysis
- [ ] Measurement error quantified
- [ ] Data collection process documented
- [ ] Raw data available for audit

### Methodology
- [ ] Method chosen for the right reasons
- [ ] Assumptions clearly stated
- [ ] Confounding factors addressed
- [ ] Statistical tests appropriate

### Validation
- [ ] Compared against external ground truth
- [ ] Not tuned on the same data judged on
- [ ] Reproducible with described steps
- [ ] Sensitivity analysis performed

### Interpretation
- [ ] Effect size meaningful in context
- [ ] Limitations clearly documented
- [ ] Alternative explanations considered
- [ ] Practical significance assessed
