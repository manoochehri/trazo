# Charter

**Status:** current

> Filled in at kickoff. Changes rarely; changes need a decision record.

**Project:** semilla
**Owner:** Michael Manoochehri (@manoochehri)
**Started:** 2026-09-27

## Why
A framework for an agentic coding team — sets up roles (PM, engineer, reviewer, security) for agentic work in VS Code, so a human directs the work instead of hand-holding one general-purpose agent.

## Goal
A clone of the semilla repo lets a human VS Code user build an app using only the agentic roles.

## Success criteria (measurable)
- A fresh clone of semilla, handed to a human VS Code user, produces a working app built entirely through the defined agentic roles (no manual coding required to complete a feature).

## Budget
- Money: Other budgets (money/infra) set per-project at kickoff or defined later.
- Time: Set per-project at kickoff or defined later.
- AI usage: Stay within Claude Code Pro weekly token limits ($20/mo).

## Hard constraints
- Must remain open source.

## Stop rule
If a fresh clone, given to a new VS Code user, still requires manual (non-agentic) intervention to ship a basic feature after two real attempts — or weekly token usage consistently blows the Pro plan's cap and would require moving to paid API budget — stop and reassess the role/command design before continuing.
